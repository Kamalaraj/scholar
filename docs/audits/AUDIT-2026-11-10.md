### Decision for Kamal: duplicate files (A-011)
All paths are tracked in git. To remove only the 30 that are byte-identical to their originals:
```bash
git ls-files | grep -E " [0-9]+(\.[^./]*)?$" | while IFS= read -r f; do
  o=$(echo "$f" | sed -E 's/ [0-9]+(\.[^./]*)?$/\1/'); [ -f "$o" ] && cmp -s "$f" "$o" && git rm -q -- "$f"; done
```
The other 27 differ from their originals (older copies) and should be reviewed by you before deleting. I did not delete anything.
